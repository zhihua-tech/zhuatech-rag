# 企业检索访问策略

Copyright © 2026 上海如静知华信息科技有限公司 · <https://www.zhuatech.cn/>

`POST /api/enterprise/rag/retrieval-access-decision` 在向量片段进入生成模型前执行一次确定性策略决策。接口同时校验租户隔离、用户组 ACL、业务用途、知识分级、来源状态、ACL 新鲜度、法务限制、来源时效、引用覆盖率和个人信息脱敏能力。

决策分为 `ALLOW`、`ALLOW_REDACTED`、`REVIEW` 和 `DENY`。跨租户、越权、来源停用或法务限制会直接拒绝；限制级知识、过期来源、引用不足或无法脱敏的信息进入人工复核；通过策略的机密信息只能以脱敏片段返回。

每次决策都会生成稳定的 SHA-256 `auditKey`，并返回必须履行的 `obligations`，方便调用方把访问证据、回答引用和后续人工审批关联到同一次审计事件。

本能力不依赖外部模型，适合在本地测试；生产部署应把用户组、文档 ACL、用途与分级字段接入企业身份系统和知识目录。
